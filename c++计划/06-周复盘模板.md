## 复盘小贴士

1. **诚实记录**，对自己不要美化也不要苛责
2. **未完成项必须有去向**（挪到下周或砍掉），不要悬而未决
3. **状态自评低于 3 分**就要警惕，立刻调整
4. **下周重点最多 3 条**，太多等于没有
5. **写完发到博客**，连载式记录学习历程，简历加分

---

## 复盘后的动作

1. 更新 [progress.md](./progress.md) 的累计数据
2. 调整 [01-本周计划-W??.md](./01-本周计划-W01.md) 的下周版本
3. 推送 GitHub
4. **关电脑，奖励自己一顿好的**
