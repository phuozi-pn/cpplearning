# 每日时间分配模板

> 根据"学期 / 暑假 / 秋招"三个阶段，每天时间分配不同。
> **不要严格按小时打卡，按"任务完成"打卡**。

---

## 学期工作日（5h 标配）

```
┌──────────────────────────────────────────┐
│  3.0h  - C++ / Linux 主线（视频 + 编码） │
│  1.0h  - LeetCode 算法 2 题              │
│  0.5h  - 英语单词（考研保底）            │
│  0.5h  - 复盘 + commit + GitHub          │
└──────────────────────────────────────────┘
```

### 推荐时段（参考，按自己作息调整）

| 时段 | 任务 | 建议 |
|---|---|---|
| 早上起床后 10min | 单词复习（昨天的） | 用 App，零碎时间 |
| 上午 / 课间 | 视频 + 阅读 | 大脑清醒，吸收概念 |
| 下午 / 晚饭后 | 编码（连续 1.5-2h） | 需要专注块 |
| 晚上 8-9 点 | 算法 2 题 | 状态稍降，正适合 |
| 睡前 30min | 单词新词 | 别碰代码，影响睡眠 |
| 睡前 15min | 复盘 + commit | 关电脑前最后一步 |

---

## 学期周末（6h 标配）

```
┌──────────────────────────────────────────┐
│  4.0h  - 主线深入（一个完整模块）        │
│  1.0h  - LeetCode 算法 2 题              │
│  1.0h  - 周博客 / 周复盘                 │
│  额外: 0.5h 英语阅读真题（选做）         │
└──────────────────────────────────────────┘
```

### 周末特点

- **大块时间**：周六上午 / 下午各 2h 连续编码
- **周日晚必做**：周复盘 + 写博客 + 推 GitHub
- **强制休息**：周六晚上 / 周日晚上至少留 2h 不学习

---

## 暑假工作日（8-10h 冲刺）

```
┌──────────────────────────────────────────┐
│  6-7h  - 主项目编码（连续大块时间）      │
│  1.0h  - LeetCode 算法 1-2 题            │
│  1.0h  - 八股 / 复习                     │
│  0.5h  - 英语单词                        │
│  0.5h  - 复盘 + commit                   │
│  额外: 30min-1h 数学视频（选做）         │
└──────────────────────────────────────────┘
```

### 暑假节奏（重要）

- **9:00-12:00**：项目编码（最专注的 3h）
- **14:00-17:00**：项目编码（下午 3h）
- **20:00-22:00**：算法 + 八股 + 复盘

---

## 暑假周末

**可以休息半天**，强制下线。剩下时间：
- 写 1 篇深度博客
- 整理代码 + 测试
- 看 1 集 DL 相关视频

---

## 9 月秋招期

```
┌──────────────────────────────────────────┐
│  早上    - 投简历 + 八股复习             │
│  下午    - 笔试 / 面试 / 模拟面试        │
│  晚上    - 算法刷题 + 面试复盘           │
│  考研    - 暂停（除英语单词）            │
└──────────────────────────────────────────┘
```

**核心心态**：从"输入"切换到"输出"，每天的任务是"面试 + 复盘"，不是"学新东西"。

---

## 弹性时间使用优先级

如果主线任务提前完成、有 1-2h 富余：

```
1. 写博客 / 整理笔记           ← 最优先
2. 多刷 1-2 道算法（巩固）
3. 项目代码优化 / 重构
4. 考研英语额外背单词 / 做阅读   ← 这就是"考研保底"
5. 考研专业课预习（暑期后）     ← 与八股重叠，一鱼两吃
6. 考研数学视频                ← 最低优先级
```

---

## 零碎时间利用（白送的时间）

| 场景 | 用途 |
|---|---|
| 通勤 / 排队 | 墨墨单词刷 10-20min |
| 课间 | 复习昨天的代码 / 翻笔记 |
| 吃饭时 | 听政治视频 / 考研 UP 主（轻负担） |
| 睡前 15min | 复习当天单词，不要碰代码 |
| 厕所 | 翻英语错题 / 公众号 |

**累计每天能白送 1-1.5h 给考研，不挤压主线。**

---

## 时间分配铁律

1. **主线 > 算法 > 考研**，顺序不能颠倒
2. **当天主线没完成 → 砍掉所有考研时间**
3. **每天最多 1.5h 考研投入**（包括单词，超过就是过线了）
4. **睡眠必须 ≥ 7h**，熬夜效率反而低
5. **每周至少 1 个半天 100% 休息**，不学不刷不焦虑

---

## 自检（每天睡前 30 秒）

```
□ 今天主线代码有进展吗？（GitHub 有 commit）
□ 今天算法刷了吗？
□ 今天单词背了吗？
□ 明天的目标清楚吗？
```

**4 个都 yes** → 安心睡觉
**有 no** → 写到 progress.md 里，下次注意
