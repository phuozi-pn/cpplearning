# 每日自检（4 问模板）

> **使用方法**：每天睡前 5 分钟，复制下面的"模板"段落到当天日期下，**诚实回答 4 个问题**。
> **不写满，写不出来的地方就是漏洞 — 漏洞才是金子。**
> 详细方法论见 [07-学习成果检验机制.md](./07-学习成果检验机制.md)。

---

## 使用规则

1. **顺序不能颠倒**：先写完今天的回答，再看明天的计划
2. **不要美化**：写"今天没学"比写"今天大概搞懂了"有意义
3. **漏洞要进队列**：所有问题 1-3 中暴露的漏洞，**全部抄进 `07-学习成果检验机制.md` 第 5 节的"漏洞复习清单"**
4. **明天第一件事**：问题 4 必须具体到"打开 xxx 文件 / 写 xxx 函数"，不能写"复习昨天的"

## 评判标准（30 秒过一遍）

```
✅ 4 个问题都有具体答案    → 安心睡觉
⚠️ Q1 选"不能" + 没写哪段 → 明天起床第一件事就是回去补
⚠️ Q2 用了术语挡          → 回听今天的费曼录音
❌ Q4 写"复习昨天"        → 不够具体，重写
❌ 整段没填                → 写"今天没学" 也比不写好
```

### Q2. 今天学的概念，能用 3 句话讲给外行听吗？
- 概念 1（fork）：
  > 一句话定义：fork 是 Linux 复制一个一模一样的进程的系统调用
  > 解决什么问题：让程序能同时做两件事（并发）
  > 关键机制：调用一次返回两次，父进程拿到子的 pid，子进程拿到 0；内存用写时复制 COW，不立刻整个复制
- 概念 2（僵尸进程）：
  > 一句话定义：子进程死了但父进程还没 wait，PCB 留在内核里
  > 解决什么问题：父进程晚一点也能拿到子的退出状态
  > 关键机制：用 wait / waitpid 回收，或 SIGCHLD 设 SIG_IGN 让内核自动收

### Q3. 今天的代码每一行我都能解释为什么这么写吗？
- [x] 第 17 行 `if (fork() == 0)` 的判断顺序是"等于 0 = 子进程"，我之前一直以为是"等于 0 = 父"，记反了

### Q4. 明天起床要做的第一件事是什么？
