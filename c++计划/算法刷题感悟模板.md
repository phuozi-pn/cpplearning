## 看题解后的最优解

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> map;
        for (int i = 0; i < nums.size(); ++i) {
            int complement = target - nums[i];
            if (map.count(complement)) {
                return {map[complement], i};
            }
            map[nums[i]] = i;
        }
        return {};
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 核心思想（一句话说清楚）

> 用哈希表存"已经见过的数"，把"找另一个数"从 O(n) 查找变成 O(1) 查找，
> 整体从 O(n²) 降到 O(n)。这就是"空间换时间"。

## 容易踩的坑

- 不能先存所有数再找，因为可能用到同一个元素两次
- 应该"边遍历边查找"，先查再存

## 二、写感悟的 3 个原则

### 原则 1：**先自己想，再看题解**
- 哪怕你的思路是错的、慢的，**先把第一反应写下来**
- 这一步是面试官最爱问的"你怎么想到的"，必须练

### 原则 2：**诚实记录翻车点**
- 不要美化自己（"我一遍就过了"）
- 真实记录"我以为...结果...才发现..."
- 这些坑就是面试 + 笔试时容易踩的，**写出来下次才能避免**

### 原则 3：**一句话总结核心思想**
- 如果不能用一句话讲清楚这题的关键，**说明还没真懂**
- 这一句话就是面试时你要讲给面试官听的"卖点"

## 五、刷题策略心法

### 不要做的事
- ❌ 一题刷一个小时不看题解（**30 分钟硬规则**）
- ❌ AC 后立刻下一题（**必须写感悟**）
- ❌ 跳过简单题（**简单题是模式入门**）
- ❌ 同一难度疯狂刷（**循环切换难度，保持挑战**）
- ❌ 只刷不复习（**艾宾浩斯曲线遗忘**）

### 推荐的事
- ✅ 30 分钟没思路 → 看题解
- ✅ 看题解后**立刻关掉**，自己默写一遍
- ✅ 一周后回看，能不能 5 分钟内重写
- ✅ 同类题连刷 3-5 道（**强化模式**）
- ✅ 周末做"专题总结"（**抽象套路**）
